# ヒアリングメモ（社内用・走り書き）2026-11-04

先方：株式会社サンプルダイニング（居酒屋・カラオケ併設業態）
出席：管理本部 佐藤部長、店舗運営課 田中課長

- 店舗は関東中心に47店。うち8店は来年春にリニューアル予定
- 衛生管理（HACCP）の記録がまだ紙。各店で温度記録・清掃チェックを手書き → 月末に本部へ郵送
- 本部で目視チェックしているが、記入漏れに気づくのが翌月になる。保健所の立入で指摘されたことあり
- 店長は1日3〜4回スマホで確認できれば十分とのこと。PCは事務所に1台のみ
- 既存システム：POSは他社製（変更不可）、勤怠は kintone で自社開発済み。どちらも入れ替えたくない
- 情報システム担当は兼務1名。セキュリティ審査は本部で必須（チェックシートあり）
- 予算感：明言なし。「年度内に決めたい」
- 田中課長：まず10店舗で試したい。冷蔵庫の温度異常はすぐ店長に通知してほしい
