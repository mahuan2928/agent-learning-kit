# サンプルダイニング様 衛生管理デジタル化のご提案（ドラフト）

## 1. 現状の課題
全45店舗で温度記録・清掃チェックを紙で運用されており、記入漏れの把握が翌月になっています。

## 2. ご提案内容
各店舗の店長がスマホから温度と清掃チェックを入力し、異常値は即時に店長へ通知します。
本部では全店の記録状況をダッシュボードで確認できます。
入力データは lark-cli 経由で既存の kintone 勤怠データと突合します。

## 3. 導入スケジュール
まず10店舗で2か月試行し、問題なければ残り37店舗へ展開します。

## 4. 費用
初期費用 0円、月額は1店舗あたり3,000円です。47店舗で月額141,000円となります。
