# 就業規則

## 第1章 勤務時間
社員の所定労働時間は1日8時間、週40時間とする。店舗勤務者はシフト表に定める時間を勤務時間とする。始業・終業の時刻は勤怠システムへの打刻によって記録する。

## 第2章 休憩
労働時間が6時間を超える場合は45分、8時間を超える場合は60分の休憩を与える。休憩は店長の指示により交代で取得する。

## 第3章 時間外労働と手当
所定労働時間を超えて勤務する場合は、事前に店長の承認を得なければならない。
時間外労働手当は、基本給を月平均所定労働時間で割った時間単価に1.25を乗じて支給する。
22時から翌5時までの深夜労働には、さらに時間単価の0.25を加算する。
法定休日に勤務した場合の休日労働手当は、時間単価に1.35を乗じて支給する。

## 第4章 年次有給休暇
年次有給休暇は、入社日から6か月継続勤務し、所定労働日の8割以上出勤した者に付与する。付与日数は次のとおりとする。

| 継続勤務年数 | 付与日数 |
|---|---|
| 6か月 | 10日 |
| 1年6か月 | 11日 |
| 2年6か月 | 12日 |
| 3年6か月 | 14日 |
| 4年6か月 | 16日 |
| 5年6か月 | 18日 |
| 6年6か月以上 | 20日 |

有給休暇の取得は、原則として取得日の1週間前までに店長へ申請する。未使用の有給休暇は翌年度に限り繰り越すことができる。

## 第5章 遅刻・欠勤の連絡
遅刻または欠勤する場合は、始業時刻の2時間前までに店長へ電話で連絡する。メッセージアプリのみでの連絡は認めない。無断欠勤が3回に達した場合は懲戒の対象とする。
